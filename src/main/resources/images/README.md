# Iconos de la Aplicación Cotizador VSS

## Descripción
Los iconos de la aplicación representan visualmente el propósito del software: un cotizador para VSS.

## Diseño
- **Fondo azul** (#2E86C1): Color corporativo que transmite profesionalismo
- **Documento blanco**: Representa las cotizaciones y documentos de trabajo
- **Líneas azules**: Simulan el contenido textual de una cotización
- **Círculo dorado con símbolo $** (#F39C12): Representa el aspecto financiero/monetario

## Archivos incluidos
- `cotizador-icon-16.png` - Icono 16x16 píxeles (para barras de herramientas)
- `cotizador-icon-32.png` - Icono 32x32 píxeles (para listas)
- `cotizador-icon-48.png` - Icono 48x48 píxeles (para escritorio)
- `cotizador-icon-64.png` - Icono 64x64 píxeles (alta resolución)
- `cotizador-icon.png` - Icono principal 64x64 píxeles

## Uso en la aplicación
Los iconos se cargan automáticamente al iniciar la aplicación y aparecen en:
- Barra de tareas (Windows/Linux)
- Dock (macOS)
- Ventana de la aplicación
- Alt+Tab / Cmd+Tab

## Tecnología
- Formato: PNG con transparencia (RGBA)
- Creados programáticamente con Python PIL
- Optimizados para diferentes tamaños de pantalla
- Compatible con JavaFX Image loading
